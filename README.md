🌐 Cyber Club Website

Bu layihə sadə və responsive bir veb sayt nümunəsidir. HTML və CSS istifadə edilərək hazırlanmışdır. JavaScript istifadə olunmayıb.

📌 Layihə haqqında

Bu sayt “Cyber Club” üçün hazırlanmışdır. Saytın məqsədi klub haqqında məlumat vermək və fəaliyyətləri təqdim etməkdir.

🧱 İstifadə olunan texnologiyalar

- HTML5
- CSS3 (Flexbox & Grid)
- Responsive Design (Media Queries)
- Font Awesome Icons
- Google Fonts (Inter)

📱 Xüsusiyyətlər

- Fully responsive design (mobile, tablet, desktop)
- Hero section with image overlay
- About section with description layout
- Activity cards section
- Clean and modern UI design

🎯 Məqsəd

Bu layihə front-end bacarıqlarımı inkişaf etdirmək və responsive layout strukturunu öyrənmək üçün hazırlanmışdır.

🚀 Gələcək planlar

- JavaScript əlavə edərək interaktivlik
- Navbar hamburger menu
- Animations və transitions
- Daha inkişaf etmiş UI/UX
